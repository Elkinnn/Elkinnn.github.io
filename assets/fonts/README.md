# Local typefaces

These original variable WOFF2 files are served locally; no external font CDN or
runtime connection is required. Each family retains its SIL Open Font License
beside the font file.

- `space-grotesk.woff2`: Space Grotesk, Florian Karsten, weights 300–700.
  Source: https://github.com/floriankarsten/space-grotesk/tree/master/fonts/woff2
- `inter.woff2`: Inter, Rasmus Andersson, weights 100–900, optical-size axis.
  Source: https://github.com/rsms/inter/tree/master/docs/font-files
- `jetbrains-mono.woff2`: JetBrains Mono, JetBrains / Philipp Nurullin / Konstantin
  Bulenkov, weights 100–800.
  Source: https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts

Downloaded 2026-11-14. All three files retain their original binaries; no
subsetting, name changes inside the fonts, or glyph modifications were applied.
