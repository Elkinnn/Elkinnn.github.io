01 / CONTEXTO

La aplicación
y su propósito.

StaySchool organiza el seguimiento estudiantil en una aplicación con vistas para docentes y representantes. Sus flujos incluyen observaciones, alertas y notificaciones.

03 / CÓMO SE CONECTA

Las piezas,
conectadas.

La aplicación utiliza Next.js y TypeScript para la interfaz y la lógica, con MongoDB y Mongoose para persistencia. La autenticación y las vistas por rol ofrecen accesos diferenciados a docentes y representantes.
