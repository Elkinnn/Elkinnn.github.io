01 / CONTEXT

The application
and its purpose.

The project explores Ecuadorian license plate recognition and vehicle speed estimation. It brings together object detection, image processing, character recognition and fuzzy inference, with a monitoring interface in Streamlit.

03 / HOW IT FITS TOGETHER

The pipeline combines YOLO detection, OpenCV segmentation, a project-specific CNN for character recognition and Mamdani fuzzy inference. Streamlit provides the monitoring interface.
